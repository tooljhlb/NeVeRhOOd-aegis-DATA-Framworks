# Public edition scope

This is a **clean-root public release** of NeVeRhOOd AEGIS DATA Frameworks, not a fork or history mirror of any internal research repository.

Included: native Rust application, C++ reference kernels, optional CUDA primitives, research reference adapter, fixtures, public API/UI assets, worker transport, examples, portable schemas, public docs and an independent test workflow.

Excluded: private execution infrastructure, hosted-notebook configuration, account links, authorization material, archived internal evidence, internal source-document catalogs and unpublished model artifacts.

The public acceptance registry starts without inherited proof references. Reproducible checks can be attached to public revisions independently.

The application is maintained for third-party software projects and AI workflows; it does not require the proprietary model system with which it was originally developed.
